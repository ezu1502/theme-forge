Options

Help

Everything you need to create and manage your VS Code theme.

Getting Started

Theme Forge lets you customize the colors of your VS Code editor with a simple visual interface. Choose a color for each category and see your changes instantly in the preview. When you're happy with your theme, click Apply to apply it to VS Code.

Editing Your Theme

Color Pickers

Use the color pickers in the Settings section to customize each color category. Changes are reflected immediately in the preview.

Preview

The Preview section shows how your selected colors look in a code editor. The preview is only a visual representation and does not affect your VS Code settings by itself.

Theme Management

Apply

Click Apply to apply your current colors to VS Code. Your selected colors will be saved to your VS Code settings.

Clear

Click Clear to discard your current edits and restore the default Theme Forge colors. This does not remove a theme that has already been applied to VS Code.

Reset Theme

Click Reset Theme to reset your VS Code theme settings.

Import

Use File → Import to load a previously exported Theme Forge theme. Importing a theme only loads its colors into the editor and preview. You must click Apply to apply the imported theme to VS Code.

Export

Want to share your theme with others, or save it for applying again later? Use File → Export to save your theme as a JSON file. Exported themes can be imported later using File → Import.

Themes

The Themes menu provides predefined color schemes that you can use as a starting point for your own theme.
